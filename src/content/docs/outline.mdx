`// 课程大纲 v0.1 · 16 章 + 附录`

从一次 API 调用，到一个 ~2500 行的编码 agent。每章固定结构：**为什么需要它 → 原理拆解 → 动手实现 → 跑起来看效果 → 练习与延伸**。每章结束项目必须可运行，且比上一章明显更强，代码按章打 git tag。

## 第〇部分 · 起点

- **[`00` 导言：把黑盒拆开](/00-intro)**
  里程碑 → 环境就绪，看完最终成品演示

- **`01` 一次 API 调用**
  里程碑 → 一个会失忆的聊天 CLI——连问"我叫什么"都答不出

## 第一部分 · 核心循环

- **`02` Tool Use：给模型一双手**
  里程碑 → 能查时间、算算术的助手

- **`03` Agent Loop：循环直到完成**
  里程碑 → 记得住你上一句的代码问答 agent

- **`04` 写与改：Write、Edit 与 diff**
  里程碑 → 能修真实 bug 的最小编码 agent

- **`05` Bash：让 agent 跑命令**
  里程碑 → 丢给它一个失败的测试，它自己修到通过

## 第二部分 · 从玩具到可用

- **`06` 系统提示词与环境感知**
  里程碑 → 注入环境后答对"当前分支有什么未提交改动"

- **`07` 权限系统：信任但确认**
  里程碑 → agent 不再能悄悄 rm -rf

- **`08` token 感知：计数、截断与缓存**
  里程碑 → API 账单下降；大输出不再把窗口撑爆

- **`09` 上下文压缩：compaction**
  里程碑 → 长对话不再爆窗口，压缩前后 usage 眼见为实

- **`10` 健壮性与会话生命周期**
  里程碑 → 429 退避、Ctrl+C 优雅取消、关终端重开对话还在

## 第三部分 · 进阶能力

- **`11` 子 agent：分而治之**
  里程碑 → 主 agent 派只读子 agent 全库搜索，自己保持清爽

- **`12` 计划、命令与 Skills**
  里程碑 → 开 todo 不漏步骤；/commit skill 按需加载眼见为实

- **`13` MCP：接入外部世界**
  里程碑 → 你的 agent 能用上整个 MCP 生态

## 第四部分 · 收尾

- **`14` 终端体验打磨**
  里程碑 → 流式 markdown、spinner、工具调用折叠
